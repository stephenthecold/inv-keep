Backup

Downloads a .tar.gz containing a consistent SQLite snapshot (uses sqlite3.backup, safe while the app is running) of every *.db file plus the uploads/ folder. Keep these somewhere off the server.

⬇ Download backup now For scheduled / automated backups, run ./scripts/backup.sh on the host (cron-friendly). See docs/BACKUPS.md.

Restore from a backup

Replaces every database row and the entire uploads folder with the contents of the uploaded bundle. The current data is saved as data/before-restore-<timestamp>/ on the server first, but only the server can roll back from it — you'll lose anything not in the bundle. Take a fresh download backup before you do this.
